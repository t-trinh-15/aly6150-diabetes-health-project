# Diabetes Access and Cost Project 2023

This project uses 2023 MEPS and 2023 BRFSS data to analyze healthcare costs, healthcare access, and cost-related barriers among adults ages 45–64 with diabetes.

## Datasets

1. MEPS 2023 Full-Year Consolidated File
2. BRFSS 2023 Annual Survey Data

## Important note

Raw datasets are not stored directly in GitHub because the BRFSS ASCII file is very large. Raw datasets are shared through OneDrive or Git LFS.

## Folder Structure

- data/raw/: raw datasets
- data/processed/: cleaned datasets
- notebooks/: Jupyter notebooks
- src/: reusable Python scripts
- outputs/tables/: exported tables
- outputs/figures/: exported charts
- report/: final report drafts
